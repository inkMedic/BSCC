# 恢复仓库原版界面（2026-10-30）

用户确认以当前仓库版本为准；登录页面允许保留独立社区实现。此要求覆盖此前为方便联调自行设计的界面。

- 奖杯入口恢复 `LeagueRankWindow`，保留原布局、赛季菜单、排名、奖杯明细和原文字资源。`power_ranking_query` 将真实社区赛季数据转换成窗口需要的格式。社区胜场30分、其他场次10分分别显示在原奖杯明细中；没有伪造官方成就、赛长或官方账号资料。
- 加号/购币入口恢复 `GetTokensWindow` 的原始币包图、金卡、横向滚动、返回状态和持卡状态。仅将 StoreQuery 和购买请求接到社区后端。币包金额按仓库 `bacommon.classic.TOKENS*_COUNT` 对齐为50/500/1200/2600；不修改已有钱包余额。
- 档案编辑和升级继续复用原窗口。库存保留原本地档案区；撤掉新增“已解锁商品”文字列表，与商店共用原目录和商品素材。
- 删除 `community_progression.py` 和 `communityleague.py`，撤掉新创的社区联赛页、分类导航、订单列表、余额条、卡到期说明以及资源帮助文字改写。后端订单及幂等记录仍保留，数据库不清空。

## 商店模板边界

仓库的 `StoreUIController` 是 DocUI 客户端渲染器，完整在线商店和在线库存由上游云端生成，源码不在此仓库。现有 `_store.py` 提供商品顺序、分组、名称翻译、显示尺寸和素材引用；社区适配使用这些现成信息及原 DocUI 组件，移除测试仪表板与额外导航。无法据此证明与缺失的云端页面逐像素一致，也没有为获取模板而登录或请求官方账号。

原版“更多”网页、赛长和账号资料仍依赖未实现的官方服务；保留原界面组件，点击使用原不可用提示，避免拿社区账号当作官方云句柄导致异常。
